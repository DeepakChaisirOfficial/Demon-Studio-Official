How to install a Bedrock download

  1. Download the .mcpack, .mcaddon, or .mcworld file.
  2. Open the downloaded file with Minecraft Bedrock Edition.
  3. For addons/resource packs, activate them from the world's Behavior Packs or Resource Packs menu.
  4. Always check the Minecraft version and device compatibility listed on the download page.

Important: This project is a static HTML/CSS/JS website. Put your real Minecraft files inside the mods/ folder and update the download paths in the JavaScript data below.
